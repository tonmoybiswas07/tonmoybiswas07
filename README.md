## 01. About Me

I'm **Tonmoy Biswas**, a MERN Stack Developer and Frontend Engineer based in **Bangladesh 🇧🇩**.

I enjoy building digital products that balance **thoughtful design, clean architecture, and practical functionality**.

My work spans responsive user interfaces, full-stack applications, REST APIs, authentication systems, and modern SaaS experiences.

I believe good software should not only work — it should be **intuitive, maintainable, secure, and built with purpose**.

- 🔭 **Currently building:** Full-stack applications and SaaS products
- 🌱 **Currently exploring:** System Design, Advanced Next.js, TypeScript
- 🧠 **Improving:** Data Structures, Algorithms, and Problem Solving
- 🎨 **Passionate about:** UI/UX, clean code, and frontend engineering
- 🤝 **Open to:** Freelance work, collaboration, and developer opportunities
- 🎯 **Long-term goal:** Becoming a world-class Full Stack Engineer
